## 🚀 Projetos em destaque

### 1. Meu DinDin — Controle Financeiro Pessoal

Aplicação web desenvolvida com Python e Django para gerenciamento de receitas e despesas pessoais.

**Principais funcionalidades e recursos:**
- Cadastro e autenticação de usuários.
- Aprovação manual de novos cadastros.
- Separação das informações financeiras por usuário.
- Dashboard para acompanhamento de receitas, despesas e saldo.
- API REST desenvolvida com Django REST Framework.
- Documentação da API com Swagger.
- Integração com PostgreSQL.
- Rotina de backup e teste de restauração do banco de dados.
- Deploy da aplicação na plataforma Render.

**Tecnologias:** Python, Django, Django REST Framework, PostgreSQL, HTML, CSS e Git.
